# E-commerce de Bolachas Artesanais 🍪

Uma plataforma de comércio eletrônico moderna desenvolvida majoritariamente em **TypeScript** e integrada com um **LLM Smart Gateway** para oferecer um assistente virtual inteligente capaz de tirar dúvidas, sugerir sabores e auxiliar os clientes na escolha dos produtos artesanais.

## 🌟 Principais Funcionalidades

- **Catálogo de Produtos:** Exibição elegante e responsiva de bolachas artesanais com detalhes de ingredientes e sabores.
- **Assistente de Vendas com IA:** Chatbot integrado que utiliza um Gateway centralizado de IA para responder dúvidas dos clientes de forma acolhedora e personalizada.
- **Tipagem Estrita:** Projeto estruturado com **TypeScript** para garantir segurança, alta performance e robustez no código.

## 🛠️ Tecnologias Utilizadas

Este projeto utiliza a seguinte stack tecnológica:

- **TypeScript** (95.2%) - Linguagem principal da aplicação.
- **CSS** (3.5%) - Estilização e design responsivo.
- **JavaScript** (1.3%) - Scripts de suporte.
- **LLM Smart Gateway** - Integração externa com IA para o chatbot de atendimento (EM EXECUÇÃO).
